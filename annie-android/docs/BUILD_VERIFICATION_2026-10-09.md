## Newly discovered build integration issue

The newer `AnnieBrowserUi.kt` references instance-scoped scroll methods that
**do not exist** in the older `AnnieBrowserSessionStore` class on the branch.
This results in unresolved function-call signatures until the old file is
adapted. The overlay's `repair-m0b-merge.py` now provides these overloads and
clears per-tab saved state on session reset. The old legacy session-level
methods remain for binary/source compatibility.
