CODE MODULES

Python, Node, Java, Go, Rust — Bailey does not care

Each code module lives in its own folder with a bailey.module.json. Bailey starts the runtime without a shell and talks to it through Module Protocol 1 over JSON lines. The module never needs direct access to Lia or your WhatsApp auth files.

{
  "protocol": 1,
  "id": "economy",
  "name": "Economy",
  "version": "1.0.0",
  "runtime": { "command": "python", "args": ["main.py"] },
  "commands": [
    { "id": "balance", "name": "balance", "section": "Economy", "description": "Show a balance" }
  ]
}
Restart Bailey Host after adding a new code module.
