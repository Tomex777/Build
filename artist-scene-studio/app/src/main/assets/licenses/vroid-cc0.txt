The original binary VRM 0.x is glTF 2.0/GLB format. Mise uses a deterministic
loader-compatibility step that normalizes JSON-escaped MIME IDs from
"image\\/png" to "image/png", preserving the decoded glTF JSON semantics.
It preserves all binary meshes, texture images, skin weights, joint matrices,
morph targets and model metadata byte-for-byte. It is NOT a static image.
The full-body dynamic pose and Android editor/renderer integration are by Mise.

The previous pale Quaternius Superhero Male was not visually an anime
character and has been removed from Mise's bundled anime asset.
