# NIGHT Channels — Agent B: curation & news

**Scope:** independent, backend-side content discovery and ranking. No website shell, account router, Azure worker, media compositor or publishing operation is changed by this module. It belongs to the one NIGHT Play combined-preview integration line; its presence on a PR is **not** evidence that any feature is deployed.

## Integration contract (A and C)

`core.cjs` exports `normalizeMeme`, `memeScore`, `chooseFourMemes`, `normalizeNews`, `chooseNews`, and de-duplication utilities. `sources.cjs` exports `redditAdapter`, `rssNewsAdapter`, `boundedGet` and `SourceError`. Runtime: Node >=18; no extra dependencies or credentials committed.

**Meme candidate:** `{id,kind:'meme',category,caption,createdAt,media:{url,mime,width,height,byteLength,perceptualHash},source:{id,provider,url,externalId,author,attributionRequired,rights,license},metrics,score?,publishable}`. Four selection cards are returned from `chooseFourMemes(items,{enabled,categories,allowDark,used,feedback,now})`; this returns an empty list when `enabled` is not explicitly true. Persist `used` per owner/channel/session (IDs *and*, where available, earlier candidate objects for near-duplicate protection). All candidate IDs are source-scoped deterministic SHA256 digests. Caution: a new `score` is an advisory ranking, **not** posting permission.

**Source rights:** `redditAdapter` needs a valid pre-authorized OAuth token provider, an explicitly allowed subreddit list, a complying User-Agent and a global app quota budget managed by integration. It uses `top?t=all` so older jokes stay eligible, bounded HTTPS responses, no redirect following, pagination tokens, local throttle and Retry-After. It **always labels Reddit media rights `unknown` and `publishable:false`**, even when source posts are publicly readable. Discovery/preview does not grant republication rights. C must require a rights-approved asset/permission record and verify every posting condition again; A should show a clear rights requirement rather than a fake Publish-ready card. Provider terms, API access, caches and licences require a legal/integration review. No unauthorized scraping fallback.

**News candidate:** `{id,kind:'news',title,summary,publishedAt,show,tags,verification,requiresReview,fingerprint,source:{id,name,url,provider,attributionRequired},autoEligible}`. `normalizeNews` only accepts fresh, trusted **exact-host** links; by default, only last 14 days. A vetted per-feed `interpreter(row)` provides show, event, tags and confirmation metadata; an item is `official` and `autoEligible` **only** when the source is marked an official channel and the record has confirmed metadata, with rumor taking priority over that status. Anything else requires owner review. Summaries are original short metadata templates, not copied article text. Do not claim all nuance is fact-checked automatically. To consolidate differently worded stories across outlets, the source-specific interpreter should set identical verified `storyKey` values such as `aurora:renewal:2026`; absent a key, the engine uses a conservative normalized title+show+event fingerprint.

**News RSS:** `rssNewsAdapter({id,name,url,official,fetchImpl,interpreter,now,maxAgeDays})`. Only configured HTTPS hosts are read; article links leaving the feed host are rejected by default. Supports bounded RSS and Atom common fields, CDATA, safe standard entities, XML DTD/ENTITY denial, a brief in-process TTL and source-specific interpretation. This lightweight parser is not a full XML reader; prefer controlled feeds and expand coverage with deterministic tests before expanding sources. Fetching actual approved external feeds is an integration gate, not covered by fixture tests.

**Hard security boundary:** None of these source and ranking helpers knows an account, channel owner, connection proof, feature toggle in durable storage or publisher credentials. Agent C must enforce those on the server before curation/scheduling **and immediately before send**, with idempotency, revocation, disconnect, and per-channel isolation; Agent A must not expose this as a directly callable unauthenticated feed or post endpoint. Returning `autoEligible:true` does **not** imply account authorization or ownership.

## Validation / handoff

`node --test night-play/channels/curation/curation.test.cjs` covers default-OFF, category opt-ins including dark, selection diversity, older funny entries, media near-duplicate hashes, prior review choices, unsafe URLs, attribution/rights, freshness, official-vs-rumor, news-interest filtering and cross-outlet duplication, OAuth pagination/rate limiting, XML safety, feed cache and oversized/redirect denial. Tests use mock source responses; there are no live Reddit or licensed newsroom responses/credentials in the repo.

**Not complete:** A must integrate the four actual cards and review choices into the locked Channels UI; C must implement owner-scoped durable settings/queue and actual rights/media publishing; D must supply approved captions/watermark; E must visually inspect 320/360/390/412px+desktop in the actual combined preview and verify remote owner isolation and authorized WhatsApp publication. Until then no live sources, WhatsApp sends or deployed cards are claimed.
