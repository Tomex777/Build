# Chromium Dino in NIGHT Play

Game engine and original pixel sprite sheet: © Chromium Authors (2014 onward), BSD 3-Clause.
This adaptation starts from the standalone extraction at
https://github.com/wayou/t-rex-runner (index.js and assets/default_.../offline-sprite.png).
Original upstream: https://chromium.googlesource.com/chromium/src/+/main/components/neterror/resources/dino_game/

License notice is retained in LICENSE.chromium.txt and the vendored game engine. The only changes inside the original engine file disable the fork's full-window arcade zoom to fit NIGHT's responsive game shell. Original Trex sprite frames and collision/jump/gravity behavior are intentionally unmodified.
NIGHT-owned UI, controls, local best and theme are in bridge.js and style.css. NIGHT is not affiliated with or endorsed by Google or Chromium.
