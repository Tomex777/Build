# Torri — Getting Started

Torri is a manga reader built around a mature local library, source, download, and reader workflow.

## Add manga

1. Open **Browse**.
2. Choose a source.
3. Open a title and add it to your library.

For local manga, open **Browse → Sources → Local source** and place supported manga folders/files in the storage location selected by Torri.

## Read

Open a title from **Library**, choose a chapter, and start reading. Reader controls let you change reading mode, scale, rotation, crop borders, and other per-series options.

Torri saves reading progress so a chapter can resume after leaving or restarting the app.

## Downloads and storage

Use **More → Download queue** to review active downloads and **More → Data and storage** for storage and backup options.

## Backups

Use **More → Data and storage → Backup and restore** to create or restore a library backup. Keep backup copies somewhere safe.
