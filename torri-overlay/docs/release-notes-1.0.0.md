# Torri 1.0.0

Torri 1.0.0 is the first production-finalized release of the Torri manga reader.

## Highlights

- Torri-specific product identity, adaptive launcher icon, monochrome icon, and native Android splash.
- Branded Library, More, Settings, About, notifications, exports, crash/support copy, and local fallback artwork.
- Mature Mihon-derived reader behavior preserved rather than rewritten.
- Reader settings, page scaling, chapter navigation, long-strip reading, and durable reading-position restore validated on Android 16.
- Minimum Android compatibility preserved at API 26.
- Cover-adaptive manga details and dark-mode presentation validated across multiple cover extremes.
- ARM64 release APK, universal APK, and Android App Bundle produced by CI.

## Compatibility

- minSdk 26
- targetSdk 36
- compileSdk 36

## Open source

Torri is built on open-source software, including Mihon. Required licenses and acknowledgements remain available from **More → About → Open source licenses**.
