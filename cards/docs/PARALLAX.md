# Parallax material study

Parallax is the proposed SSS visual tier. This is a programmed SVG study of its platinum shell, asymmetric recessed frame, selective prismatic edge foil, foreground character shadow and glass rank typography. The archived renderers are unchanged.

The reference illustration is the pinned official Soul Resonance Byakuya art already acquired for the collection. His existing form and A assessment remain unchanged. The specimen is titled PARALLAX and visibly labelled as a material study, with the reference character's actual grade in the lower caption. It is not added to the active collection or bot manifest.

Characters must cross the inner frame through their real silhouette. A background aura crossing the frame does not satisfy this. Here, Byakuya's head, hair, arm and cape sit in front of the platinum architecture; only the original source pixels are used.

Run from the cards package with pinned Chrome for Testing 131.0.6778.204:

```bash
NIGHT_BROWSER_PATH=/path/to/chrome-headless-shell node bin/parallax-study.mjs 3000
```

The output includes a 3000 x 4800 PNG, embedded SVG, 320 x 512 phone proof and a source/QA record in `dist/parallax-study/`.
