# Naruto in the three original designs

The Naruto showcase changes the character only. `src/fronts.mjs`,
`src/materials.mjs`, `src/geometry.mjs`, `src/index.mjs`, the studio styles,
and `examples/cards.json` are byte-for-byte unchanged from the existing
Artist Editions. No new Naruto-specific framing, palette, effects or layout.

All three cards use the same official Naruto illustration, so the differences
come from the existing Nocturne, Tidelight and Verdant designs.

## Generate all three cards

```sh
npm ci
npx playwright install chromium
node bin/character.mjs examples/characters/naruto.json dist/naruto 3000
node bin/character-proof.mjs examples/characters/naruto.json dist/naruto 3000
node bin/character-studio.mjs examples/characters/naruto.json dist/naruto 3000
node bin/verify-character.mjs examples/characters/naruto.json dist/naruto 3000
```

This produces three **3000 × 4200 PNGs**, standalone SVGs with embedded fonts
and artwork, the generated card definitions, and artwork provenance. An
existing Chromium can be selected with `NIGHT_BROWSER_PATH` as in the main
README. Raster width is the last argument; the SVG master remains scalable.

## Supply another character

Copy `examples/characters/naruto.json` to a new character profile. Set its
`id`, `name`, optional `subtitle` and `description`, and `artwork` metadata.
Use the actual local artwork dimensions and rights. Put the artwork inside
the project, supply its relative `localPath`, and set its SHA-256 digest.
Transparent portrait artwork works across all three supplied templates.
The command generates all three designs from that one profile; no SVG or
CSS editing is required.

```js
import {characterCards} from './src/characters.mjs';
import {loadCharacterAssets} from './src/character-assets.mjs';
import {renderCard} from './src/index.mjs';

const cards = characterCards(existingTemplates, characterProfile);
const assets = await loadCharacterAssets(characterProfile);
const svg = renderCard(cards[0], assets);
```

The character binding preserves each original template's material, theme,
composition, layout, collection, edition, number, seed, subject rectangle and
focal point. Different source illustrations can naturally crop differently.
No source artwork or AI upscaling is generated by this workflow.
