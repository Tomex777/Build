# ABR for Juice WRLD
- Android **minSdk 26** and applicationId `com.nice.juicewrld` are mandatory.
- No redundant controls, native-default text fields or noisy filler copy.
- Intentional custom Compose input and polished original visuals; icons should be vectors.
- Real catalog only: no fabricated songs, fake listen controls, wrong artist links, copied paid music, lyric scrapes or unlicensed audio streams.
- Offline storage and bookmarks/favorites must actually persist. Never quietly convert an error into empty data.
- MusicBrainz requires meaningful User-Agent and maximum one API call per second. Don't background poll.
- Don't call it complete until tests, real app install, UI inspection and device interactions pass.
- Keep all work here, not on Slumber, NIGHT Social or other projects.
