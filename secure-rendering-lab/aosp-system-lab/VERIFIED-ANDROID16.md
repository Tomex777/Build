# Verified Android 16 system-lab result

Verified on 2026-09-22 by the `Secure Rendering System Emulator Probe` GitHub Actions workflow.

## Environment

```text
Fingerprint: Android/sdk_phone64_x86_64/emu64x:16/BE2A.250530.026.D1/13818094:userdebug/test-keys
Build type: userdebug
ro.debuggable: 1
Build tags: test-keys
```

The emulator was started with a writable system image. The first remount disabled verity and enabled overlayfs, then required a reboot. After reboot:

```text
Remounted /system as RW
Remounted /vendor as RW
Remounted /product as RW
Remounted /system_dlkm as RW
Remounted /system_ext as RW
/system_ext write test: SUCCESS
```

## Installed state

The platform-test-key-signed APK was installed at:

```text
/system_ext/priv-app/SecureRenderingSystemLab/SecureRenderingSystemLab.apk
```

PackageManager reported the app as both `SYSTEM` and `PRIVILEGED`.

The following permissions were granted:

```text
android.permission.CAPTURE_SECURE_VIDEO_OUTPUT: granted=true
android.permission.CAPTURE_VIDEO_OUTPUT: granted=true
android.permission.CAPTURE_BLACKOUT_CONTENT: granted=true
android.permission.READ_FRAME_BUFFER: granted=true
```

## Secure virtual-display result

The app's ADB autorun self-test reported:

```text
CAPABILITIES|buildType=userdebug|systemApp=true|platformSigned=true|secureVideo=GRANTED|video=GRANTED|blackout=GRANTED|framebuffer=GRANTED
CREATE|SUCCESS|displayId=2|flags=0x6
RESULT|FRAME|sampleBytes=8192|checksum=2012022784
```

The probe repeated successfully on additional display IDs with the same test-frame checksum.

## What this establishes

This verifies that the secure virtual-display gate that rejected the normal APK can be opened in a controlled Android 16 system environment by running the lab as a platform-signed privileged system app with the appropriate grants.

The experiment is deliberately limited to content generated by Secure Rendering System Lab itself. It does not implement global capture of secure layers from unrelated applications, and it does not alter SurfaceFlinger's permission checks.
